Statistikk

Denne siden inneholder statistikk for win/loss/starplayer for alle personene som er inkludert på siden. Statistikken blir oppdatert hvert 30. minutt, så lenge Zimma ikke er på ferie. Det kan hende at det tar litt til for at statistikken blir oppdatert, på grunn av begrensininger i hvor ofte vi kan hente data fra Brawl Stars API.
